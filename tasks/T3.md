# Task: bug report - tasks missing when paging through a filtered list

A user of TaskFlow sent us this report:

> "When I filter tasks and page through them, some tasks never show up - mostly the ones at the end of the list.
> I counted: the project says it has 15 tasks, but the board only ever shows me the first 12. Same thing when I
> filter by status, the last few are just gone. Nothing in the error log. Used to work fine, I think."

## What to do

1. Find the cause and fix it so that every task in a filtered (or unfiltered) list is reachable by paging through it.
2. Add a regression test in `test/` that fails without your fix and passes with it.
3. Keep the change minimal and follow `CONVENTIONS.md`.

## Before you finish

Run `npm test` and `npm run lint`; both must pass.
